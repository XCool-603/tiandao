## ⚡ 核心机制与突破

1. **人人皆主角，开辟任意题材大千天地**
   * 支持一键快速建立任意流派小说，或完全自主输入题材设定。
   * 无天定免死主角光环，胜负生死全凭各方行动克制与因果判定。
2. **绝对的双盲机制（战争迷雾）**
   * 角色 **绝对看不到其他人的内心独白与真实底牌**。
   * 每个角色拥有三元组决策结构：
     * **`inner_thought`（内心深层算计）**：仅天道与史官可见，对外绝对保密。
     * **`speech`（公开言语伪装）**：虚与委蛇、装傻充愣、大义名分。
     * **`action`（具体动作与暗招）**：移形换位、袖中扣符、神行暗遁、科技武器充能。
3. **Turbo 极速双盲推演矩阵 & 确定性状态机**
   * 单次深度推理完成全员决策与天道裁决，推演耗时缩短至 10 秒级。
   * 道具消耗与获取、伤势记录、生死走向严格落地状态机，杜绝虚空变出道具或瞬间凭空愈合。
4. **史官文学淬炼与高性能打字机输出**
   * 动态匹配对应题材的宗师级文风（都市热血、悬疑窒息、科幻宏大、修仙冷峻、历史古雅）。
   * 前端采用增量段落流式追加引擎，零卡顿流畅输出数十万字长篇巨作。
5. **🎙️ 真人有声听书系统 (Neural Audiobook Studio)**
   * 智能神经声学引擎，优先嗅探并匹配高品质真人自然音色（如云希·热血少年男音、晓晓·沉浸生动女音、云扬·评书历史音等）。
   * 搭载律动声波跳动频谱条、多档快捷倍速药丸（0.85x ~ 1.5x）、段落高亮跟读与自动平滑滚动。
   * 支持段落直达：点击正文任意一段即可立即从该段开播，畅享录音室级别的有声畅听体验。

## 🐳 Docker 一键部署（推荐云端 / 服务器部署 🌟）

项目已全面容器化，支持 Docker & Docker Compose 极速一键部署，提供开箱即用的高并发隔离与长程自动存盘支持。

### 1. 快速启动（推荐）
```bash
# 1. 克隆代码仓库
git clone https://github.com/XCool-603/tiandao.git
cd tiandao

# 2. 复制环境配置文件（填入你的大模型 API KEY，留空亦可直接使用沙盒模拟模式）
cp .env.example .env

# 3. 一键构建并后台启动
docker compose up -d --build
```
> **提示**：
> - **Linux / macOS 用户**：可直接运行快捷脚本 `./docker-run.sh`
> - **Windows 用户**：可直接双击根目录下的 [`docker-run.bat`](file:///c:/Work/天道/docker-run.bat)

### 2. Docker 原生命令直接运行
```bash
# 构建镜像
docker build -t tiandao:latest .

# 启动容器（映射宿主机 28088 与 28089 端口，并挂载本地正文输出目录）
docker run -d \
  --name tiandao \
  --restart unless-stopped \
  -p 28088:8088 \
  -p 28089:8089 \
  -v $(pwd)/output:/app/output \
  --env-file .env \
  tiandao:latest
```

### 3. 端口与持久化说明
| 宿主机端口 | 容器内端口 | 说明 |
| :--- | :--- | :--- |
| **`28088`** | `8088` | **Web 创作者 Studio 控制台** 及 RESTful API（浏览器打开 `http://<IP>:28088`） |
| **`28089`** | `8089` | **WebSocket 全双工推演通道**（拟真打字机流式输出专属信道） |

* **数据持久化**：挂载的 `./output:/app/output` 会实时持久化已生成的全书长篇小说章节（`novel_chapter_xx.md`）、分卷细纲总账与世界历史，容器销毁重建数据永不丢失。
* **容器常用命令**：
  ```bash
  # 查看运行日志与推演进度
  docker compose logs -f

  # 重启服务
  docker compose restart

  # 停止并移除容器
  docker compose down
  ```
