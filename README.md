# 🌌 【天道】—— 多智能体凡人流修仙小说自动演化系统

> **“大道五十，天衍四九。人遁其一，各怀鬼胎。”**  
> 这是一个基于大模型（LLM）驱动的**生成式多智能体修仙小说创作引擎**。

---

## ⚡ 核心机制与突破

1. **人人皆主角，默认零角色开天辟地**
   * 系统启动和重置时角色数量为 **0**。绝无天定免死主角光环。
   * 第一轮运转时，天地异象爆发，自发引渡首批争渡修士入局。
2. **绝对的双盲机制（战争迷雾）**
   * 角色 **绝对看不到其他人的内心独白与真实底牌**。
   * 每个角色拥有三元组决策结构：
     * **`inner_thought`（内心深层算计）**：仅天道与史官可见，对外绝对保密。
     * **`speech`（公开言语伪装）**：虚与委蛇、装傻充愣、大义名分。
     * **`action`（具体动作与暗招）**：移形换位、袖中扣符、神行暗遁。
3. **铁壁防崩与请求控频护栏（保护自建与私有模型）**
   * 严格单并发串行交接，彻底杜绝瞬间并发冲垮后端服务器。
   * 内置 1.0s 请求冷却缓冲，支持 429/502/504 指数退避重试与平滑熔断降级。
2. **天道因果律裁判**
   * 杜绝角色“自嗨无敌”。伤害结算、法宝品阶压制、偷袭成功率全部由天道判定。
   * 当剧情陷入日常或停滞时，天道主动降下【守护古兽暴走、禁制崩塌、异宝现世】强行激化矛盾。
3. **史官文学淬炼**
   * 不直接拼凑对话，而是由史官 Agent 将推演日志精炼为经典的**凡人流小说正文**（动作细节考究、心理博弈层层推进、肃杀沉郁）。

## 🚀 启动方式

### 方式一：网页沉浸式控制台（强烈推荐 🌟）
直接双击运行 [`start_web.bat`](file:///c:/Work/天道/start_web.bat) 或在终端执行：
```powershell
python web_server.py 8088
```
浏览器打开：**`http://localhost:8088`**
* **指挥天道**：随时输入【天道法旨】（如：“潭底冲出古剑”、“南宫璇寒毒爆发”、“天降神雷”）强行干涉命运。
* **窥探众生**：查看角色表面言语 vs 识海深处的阴毒算计与底牌。
* **一键著书**：随时点击【敕令史官著书】生成正统凡人流长篇小说。
* **免API沙盒**：支持一键勾选【模拟模式】，随时测试演化效果。

### 方式二：终端命令行演化
```powershell
# 模拟演练模式（无需 API）
python main.py --mock

# 真实大模型推演
python main.py --rounds 5
```

## 🔄 一键更新与版本升级

系统深度支持全自动从 GitHub 同步最新演化与打字机引擎：

* **方式一：双击一键更新**：在根目录下直接双击运行 [`update.bat`](file:///c:/Work/天道/update.bat)，自动拉取最新代码并升级依赖。
* **方式二：Web 界面一键更新**：在创作者控制台右上角点击 **「🔄 检查更新」**，或在管理端（`admin.html`）点击 **「⚡ 立即拉取 GitHub 最新代码并升级」**。
* **方式三：Git 命令行**：
  ```powershell
  git pull origin main
  pip install -r requirements.txt
  ```
